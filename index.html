How ValueLens V3 works

Launch price: taken from the indexed source where available. Current value: V3 estimates depreciation from device age and category because a live resale feed is not connected yet. AI Finder: deterministic natural-language parsing + weighted spec matching, so it does not fail just because a model name contains a number.

Catalogue source: a public 2025 mobile dataset with launch prices and specifications. The V3 loader parses its CSV directly; tablets and oversized devices are filtered out. The dataset is useful for prototyping, but current market prices and popularity should be replaced with licensed/live sources before presenting them as real-time market facts.
